# Python 算法刷题速成笔记 · Day 1：基础语法

> 定位：已有编程基础，快速掌握 Python 常用语法，为后续 LeetCode 刷题做准备。
> 学习内容：变量与输入输出、运算符、条件、循环、函数、常见易错点。

## 1. 变量与基本类型

Python 无需提前声明变量类型，使用 `=` 绑定对象。

```python
a = 10                # int
b = 3.14              # float
name = "Python"       # str
ok = True             # bool
empty = None          # NoneType
print(type(a))        # <class 'int'>

x, y = 1, 2           # 解包赋值
x, y = y, x           # 交换变量
```

常用转换：`int()`、`float()`、`str()`、`bool()`。注意 `int("12.3")` 会报 `ValueError`；`int(3.9)` 得到 `3`，不是四舍五入。

## 2. 输入与输出

`input()` **始终返回字符串**。普通算法练习常见输入方式：

```python
n = int(input())                     # 一行一个整数
a, b = map(int, input().split())     # 一行两个整数
nums = list(map(int, input().split()))  # 一行多个整数
```

常用输出：

```python
print(1, 2, 3)                # 默认空格分隔、末尾换行
print(1, 2, 3, sep="-")       # 1-2-3
print("hello", end=" ")       # 不立即换行
name, score = "Tom", 89.567
print(f"姓名：{name}，成绩：{score:.2f}")  # 成绩：89.57
```

在线评测题的输出需严格匹配要求：题目只要数字就不要额外输出“和：”“结果：”。

## 3. 运算符

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `+ - *` | 加减乘 | `2 * 3 == 6` |
| `/` | 普通除法 | `10 / 3` 得浮点结果 |
| `//` | 向下取整除法 | `10 // 3 == 3`；`-10 // 3 == -4` |
| `%` | 取模 | `10 % 3 == 1` |
| `**` | 乘方 | `2 ** 3 == 8` |
| `== != > < >= <=` | 比较 | `a >= b` |
| `and or not` | 逻辑运算 | `a > 0 and b > 0` |
| `in / not in` | 成员判断 | `'a' in 'cat'` |

可写链式比较：`1 <= x <= 10`。`and` / `or` 会短路，且结果不一定是布尔值，例如 `0 or 5` 得 `5`，`0 and 5` 得 `0`。

## 4. 条件判断

```python
score = 85
if score >= 90:
    level = "优秀"
elif score >= 60:
    level = "及格"
else:
    level = "不及格"

status = "YES" if score >= 60 else "NO"  # 条件表达式
```

Python 用**冒号 + 缩进**表示代码块；注意相等边界。例如求三个数最大值时，全部用严格大于 `>` 可能在两个最大数相等时得到错误结果：

```python
if a >= b and a >= c:
    ans = a
elif b >= a and b >= c:
    ans = b
else:
    ans = c
```

## 5. 循环与 range

`range(start, stop, step)` 包含 `start`、不包含 `stop`：

```python
for i in range(5):          # 0,1,2,3,4
    print(i)
for i in range(2, 11, 2):   # 2,4,6,8,10
    print(i)
for i in range(5, 0, -1):   # 5,4,3,2,1
    print(i)

n = 12340
while n > 0:
    digit = n % 10          # 取末位
    n //= 10                # 去末位
```

直接遍历元素：

```python
nums = [10, 20, 30]
for x in nums:
    print(x)
for i, x in enumerate(nums):
    print(i, x)             # 同时获取下标与元素
```

`break` 结束当前层循环；`continue` 跳过当前轮；`for/while ... else` 的 `else` 仅在循环**没有被 break 中断**而正常结束时执行。

整数反转的常用写法：

```python
n = 12340
reversed_num = 0
while n > 0:
    reversed_num = reversed_num * 10 + n % 10
    n //= 10
print(reversed_num)         # 4321
```

## 6. 函数

```python
def add(a, b):
    return a + b

def power(x, n=2):         # 默认参数
    return x ** n

print(power(3))             # 9
print(power(2, 5))          # 32
```

- `print()` 负责显示，`return` 负责将值返回给调用者；无显式 `return` 时返回 `None`。
- 支持关键字参数：`power(n=3, x=2)`。
- `*args` 收集额外的位置参数为元组，`**kwargs` 收集额外的关键字参数为字典。
- 用 `return a, b` 可以返回一个元组，再通过 `x, y = func()` 解包。

```python
def calculate_sum(*args):
    ans = 0
    for x in args:
        ans += x
    return ans

print(calculate_sum(1, 2, 3))  # 6
```

### 可变默认参数陷阱

不要用 `nums=[]` 作为希望每次调用重新创建的默认列表；默认参数对象会被复用。

```python
def add_element(x, nums=None):
    if nums is None:
        nums = []
    nums.append(x)
    return nums
```

`is None` 用于判断是否为 `None`；`==` 比较值。不要简单用 `if not nums` 替代 `if nums is None`，因为空列表也是假值。

### 作用域与主程序入口

- 函数内定义的变量通常是局部变量；需要重新绑定全局变量时才使用 `global`。
- 主程序入口的固定写法为：

```python
if __name__ == "__main__":
    print("直接运行当前脚本")
```

注意 `__main__` 前后各有两个下划线，`"main"` 不正确。

## 7. Day 1 综合例题：数字分析器

要求：输入正整数，计算各位数字之和、反转后的整数、是否为回文；不转字符串、不使用列表。

```python
def analyze_number(n):
    original = n
    digit_sum = 0
    reverse_num = 0
    while n > 0:
        digit = n % 10
        digit_sum += digit
        reverse_num = reverse_num * 10 + digit
        n //= 10
    return digit_sum, reverse_num, original == reverse_num

if __name__ == "__main__":
    a, b, c = analyze_number(1221)
    print(a, b, c)  # 6 1221 True
```

关键点：`digit` 是当前末位数字，`digit_sum` 是累计和，两者不可混用；循环会破坏 `n` 的原始数值，因此先保存 `original`。对于正整数 n 的位数 d，时间复杂度 O(d)，额外空间 O(1)。

## 8. 本日练习发现的易错点

1. **输入格式**：题目说“一行两个整数”，应优先考虑 `a, b = map(int, input().split())`。
2. **输出约定**：`YES` 与 `yes` 不同，漏写 `print()` 也不满足题意。
3. **边界条件**：多个相等的数、除数为零都要正确处理。
4. **除零判断**：`not y` 在 `y == 0` 时为 `True`；应先判断 `y == 0` 再决定是否做除法。
5. **变量一致性**：读取 `n3` 后循环要使用 `n3`，不要误用前一题的 `n`。
6. **名称遮蔽**：尽量避免用 `max`、`sum`、`list` 等内置名称当变量名。
7. **返回顺序**：题目要求“先最小后最大”，就要 `return min(...), max(...)`。
8. **变量的当前状态**：`while n: n //= 10` 之后 `n == 0`，不能继续用它与原值比较。
9. **输出格式细节**：`print(f"{a, b}")` 输出元组形式，如 `(10, 20)`；`print(a, b)` 输出以空格分隔的两个值。
