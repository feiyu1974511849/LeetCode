# **Python 算法刷题 7 天速成学习计划**

## **一、学习目标**

### **1. 学习背景**

- 已经具备 C/C++ 编程基础，有算法刷题经验。
- 掌握 Java 基础。
- 接触过少量 Python，但对 Python 的语法和常用写法不够熟悉。

### **2. 核心目标**

本阶段主要是为了快速掌握 Python，为后续 LeetCode 算法刷题和技术面试做准备。

具体目标：

1. 熟练掌握 Python 基础语法。
2. 熟练使用 Python 内置数据结构。
3. 掌握算法刷题常用的标准库。
4. 熟悉链表、树、栈、队列、堆等数据结构在 Python 中的使用。
5. 掌握 Python 常见算法代码写法。
6. 能够独立使用 Python 编写基础算法程序。

### **3. 学习原则**

- 不需要从零开始学习编程，重点关注 Python 的语法和使用方式。
- 不进行 C++、Java 与 Python 的逐项对照。
- 每学习一个知识点，立即进行对应练习。
- 练习题以巩固 Python 基础为主，不急于大量刷 LeetCode。
- 以快速掌握、能够独立编写代码为目标，不追求 Python 语言的全面深入。

## **二、7 天学习路线**

| 天数    | 学习主题        | 核心目标                      |
| ----- | ----------- | ------------------------- |
| Day 1 | Python 基础语法 | 掌握基本语法、循环、函数              |

# **四、学习方式与教学要求**

本阶段采用知识点驱动的教学方式。

### **1. 知识讲解**

- 介绍知识点的基本概念。
- 讲解 Python 的具体语法。
- 介绍常见用法和适用场景。
- 补充算法刷题中的注意事项。

### **2. 代码示例**

- 提供可以直接运行的代码。
- 对关键代码进行解释。
- 展示运行结果。
- 不堆砌复杂代码，优先使用简单示例。

### **3. 配套练习**

每个知识点后安排 2～5 道基础练习。

要求：

- 练习题必须与当前学习内容直接相关。
- 由简单到复杂。
- 不提前引入尚未学习的知识点。
- 优先考察当前知识点的使用。
- 不以 LeetCode 难题作为基础练习。

### **4. 代码批改**

完成练习后，将代码提交给 ChatGPT。

要求检查：

- 语法是否正确。
- 逻辑是否正确。
- 是否存在边界条件问题。
- 是否存在不合理的写法。
- 是否有更简洁、规范的 Python 实现。

### **5. 阶段验收**

每完成一个大的知识模块，安排一次综合练习。

只有掌握当前知识点后，再进入下一个模块。
